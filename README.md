[![make.fun](https://make.fun/badge/u-donrulezz-the-absurd-clause-contest-035cc0f1.svg)](https://make.fun/competitions/u-donrulezz-the-absurd-clause-contest-035cc0f1)

[![reward](https://make.fun/badge/u-donrulezz-the-absurd-clause-contest-035cc0f1/cocolats18-svg/u-donrulezz-the-absurd-clause-contest-035cc0f1-entry/reward.svg)](https://make.fun/competitions/u-donrulezz-the-absurd-clause-contest-035cc0f1)

One line, 200 characters at most: an absurd clause hidden deep inside a terms-of-service agreement. A judge model reads the clauses in pairs and the funniest one takes the reward.

## Entry

> Clause 9: by using this service, you agree to apologise in writing to any goose offended by your conduct, within seven (7) business days of the honking.

`main.ts` writes that single original sentence to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written.
